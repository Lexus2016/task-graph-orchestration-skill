# Quillstream changelog

## 2026-08-14
- **Paid plans:** rate limit raised from 600 to 900 requests per minute. Free plan unchanged.
- `Retry-After` now returned in seconds instead of milliseconds.

## 2026-05-20
- New `/v2/batch` endpoint (counts as one request per batch).

## 2026-03-02
- Rate limits unified at 600 requests per minute for all plans.
